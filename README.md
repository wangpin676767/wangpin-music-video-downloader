# 王品音樂影片下載器

Windows 10 音樂與影片下載器。可一次貼入多個網址，選擇下載影片或擷取 MP3 音樂，並管理下載紀錄。

## 使用
1. 雙擊 `王品音樂影片下載器.exe`。程式會在本機（僅 127.0.0.1）啟動繁體中文介面，並用已安裝的 Brave 開啟。
2. 貼上 HTTP(S) 網址（可一次貼多個，一行一個，最多 50 個），選擇「影片」或「音樂（MP3）」與輸出位置。影片可選畫質（最佳 / 1080p / 720p / 480p）。
3. 按「全部下載」會依序下載每個網址，下方清單顯示每支的完成／失敗；取消會停止整批。一般解析找不到影片時，會自動用 Brave 偵測網頁播放器（最多約 35 秒），適用於部分 JavaScript 與 iframe 播放器。可看到進度、合併狀態，也可取消；取消後會保留 `.part`，重新下載可續傳。
4. 預設存到本資料夾的「影片」。成功紀錄會保留，可開啟所在資料夾；每筆紀錄可按「刪除」，或按「清除全部紀錄」（只刪紀錄，不刪影片檔）。
5. 重複雙擊 EXE 會沿用同一個執行中的實例。

請用 `王品音樂影片下載器.exe` 或 `啟動王品音樂影片下載器.cmd` 啟動。直接雙擊 `index.html` 只會開啟介面原始檔，沒有下載服務；頁面會顯示啟動說明。正常分頁的網址以 `http://127.0.0.1:` 開頭。若程式已關閉或電腦重新啟動，請再次啟動 EXE，使用新開啟的分頁。

## 內容
- `王品音樂影片下載器.exe`：打包好的程式，不需另外安裝 Python。
- `tools/`：yt-dlp、FFmpeg、Deno（隨附工具，來源與雜湊記於 `tools/sources.json`）。
- `影片/`：預設下載位置。
- `app.py`、`media_resolver.py`、`index.html`：原始碼。Playwright 驅動已包含在 EXE；偵測使用本機已安裝的 Brave，不需另下載 Chromium。

## 重新建置
在本資料夾以 PowerShell 執行 `建置.ps1`。它會建立 Python 3.12 環境、安裝建置依賴、下載官方工具並打包 EXE。

## 驗證
`test_audio.py` 驗證封裝後的音樂／影片切換、批次 MP3 下載、音訊與影片解碼、類型設定記憶和介面 JavaScript。`test_integration.py` 驗證 MP4、HTML video、HLS、DASH 合併、畫質上限、取消/重試、錯誤、設定持久化與本機安全。`test_dynamic.py` 驗證封裝後的動態播放器、Referer/UA、取消時的程序清理與重試；`test_resolver.py` 獨立驗證主清單選擇及 DRM。

封裝測試應設定 `VIDEO_DOWNLOADER_TEST_ROOT`，指向含 EXE 和 tools 的隔離測試資料夾，避免修改使用者設定或紀錄。`test_audio.py` 會自行建立測試資料夾，因此必須指定尚未存在的完整路徑。

## 限制
- 不保證所有網站。支援 yt-dlp 能解析的網站、HTML video、可觀測的 JavaScript／iframe 播放器與 MP4／WebM／HLS／DASH。偵測優先使用主清單，忽略常見片段與廣告 iframe。
- DRM、需登入或付費、CAPTCHA、部分特殊播放器，以及網站存取限制仍可能擋下下載，介面會顯示原因。
- 主介面沿用 Brave 的既有設定檔。播放器偵測另外使用短暫的無介面工作階段，不讀取既有設定檔、cookies 或登入資訊；取消或完成後會關閉。
- 畫質受網站當下提供的來源與格式資訊限制；選 1080p 不會把低解析度來源升成 1080p。
- 每個網址只下載單支影片，不下載整份播放清單；直播不自動錄製。
- 請只下載你有權下載的內容。

## 音樂或影片

下載前可選擇「影片」或「音樂（MP3）」。音樂模式會下載最佳可用音訊並轉成 MP3，不保留影像；轉檔無法提升來源音質。音樂模式不使用畫質選項。整批使用同一下載類型，設定會記住上次選擇。原有紀錄與儲存位置繼續沿用。
